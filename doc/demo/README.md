# Preview capture

`preview.png` shows the plugin's actual Neovim UI output, captured on
2026-10-13 and rasterized with a monospace font.

- Plugin baseline: `44987e1`; no runtime changes.
- Neovim 0.12.5, obsidian.nvim v3.16.8, locally supplied Markdown parsers.
- Built-in `habamax` colors, Menlo 16 px, 84 columns by 40 rows.
- Attached, enabled, settled; six ready embed rows and no failed rows.

The capture shows whole-note, heading/alias, block, relative/recursive,
inline, and table embeds. Obsidian's UI/footer and the host Markdown
highlighters were disabled to avoid overlapping conceal rules. The plugin
used both Markdown parsers for its own analysis and previews.
